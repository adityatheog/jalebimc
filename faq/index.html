Help

Frequently asked questions

Quick answers about joining, versions, the store and appeals.

What is Lifesteal?

Lifesteal is a survival mode where winning a PvP fight takes a heart from the loser and adds it to you. Lose all your hearts and you are out of the fight, unless someone brings you back.

What is the JalebiMC server IP?

Java Edition: fun.jalebimc.in port 30109. Bedrock Edition: bedrock.jalebimc.in port 30186. See the How to Join page for step-by-step instructions.

Which Minecraft versions can I join with?

Java Edition supports versions 1.7.2 to 26.x. Bedrock players connect through Geyser.

Can Bedrock players play with Java players?

Yes. Bedrock players on mobile, console or Windows join the same worlds as Java players.

Where do I get help or report a problem?

Join our Discord. Staff and the community can help with questions, bugs and reports.

I was banned or muted. What can I do?

If you believe it was a mistake, submit a request on the appeal page. Staff review each appeal, but a review does not guarantee a change.

How do I buy a rank, key or coins?

Visit our web store at store.jalebimc.in. The Store page on this site lists current ranks, keys and coin packages with prices in rupees.
