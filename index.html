About JalebiMC

A place you will want to log into every day

JalebiMC is a Lifesteal SMP for Indian players. It is built to be fast, fair and easy to join on whatever device you play on.

Made for players in India

We set the network up with Indian players in mind, so connections stay short instead of bouncing through a far-away region.

Java and Bedrock, same world

Geyser lets friends on mobile, console or Windows play alongside Java players. Nobody gets left on a different server.

A stable, modern setup

A Velocity proxy fronts Paper servers, tuned for smooth chunk loading and fewer surprises when a fight gets busy.

Shaped by the community

Features and changes are guided by what players tell us in Discord. If something feels off, say so — we read it.
