About the network

Built for serious, everyday play

JalebiMC runs on a modern Velocity network with Paper backends underneath — built for players across India who want a fast, stable place to log in every day, on Java or Bedrock.

Velocity Network

A Velocity proxy sits in front of the network, so every player joins through one address and one consistent experience.

Paper Backend

Gameplay runs on an optimized Paper server, tuned for smoother chunk loading and fewer surprises during heavy PvP.

Indian Routing

Infrastructure is set up specifically to keep connections short for players across India, rather than routing through a distant region by default.

Cross-Play

Geyser lets Bedrock players on console, mobile or Windows play alongside Java players on the exact same worlds.

Community Driven

Changes and new features are shaped around what the community is actually asking for in Discord.

How to play

Join in three steps

  1. 1

    Copy the address

    Use the Copy buttons above. Java uses the Java address; Bedrock uses the Bedrock address and port.

  2. 2

    Add the server

    Java: Multiplayer → Add Server. Bedrock: Play → Servers → Add Server. Paste the address, and the port on Bedrock.

  3. 3

    Join and play

    Hop in, and ask in Discord if you get stuck — the community and staff are there to help.

FAQ

Common questions

Which Minecraft versions can I join with?

Java Edition supports 1.7.2 – 26.x. Bedrock players connect through Geyser.

Can Bedrock players play with Java players?

Yes. Bedrock players on mobile, console or Windows join the same worlds using the Bedrock address and port shown above.

Where do I get help or report a problem?

Join our Discord. Staff and the community can help with questions, bugs and reports.

I was banned or muted. What can I do?

If you believe it was a mistake, submit a request on the appeal page. Staff review submissions, but a review does not guarantee a change.

Does the server have a store?

Yes — visit store.jalebimc.in.
