How to join JalebiMC

Pick your edition, add the server, and you are in. It takes about a minute.

Java Edition

Works with Java versions 1.7.2 – 26.x.

  1. 1

    Open Multiplayer

    Launch Minecraft Java Edition on any supported version and choose Multiplayer.

  2. 2

    Add the server

    Select Add Server, name it JalebiMC, and enter the address fun.jalebimc.in:30109.

  3. 3

    Join and play

    Save it, select JalebiMC from your list, and click Join Server.

Bedrock Edition

For mobile, Windows and console players, through Geyser cross-play.

  1. 1

    Open Servers

    Launch Minecraft Bedrock Edition, press Play, then open the Servers tab.

  2. 2

    Add the server

    Choose Add Server, name it JalebiMC, and enter the address bedrock.jalebimc.in with port 30186.

  3. 3

    Join and play

    Save it and tap JalebiMC to join the same world as Java players.
